# Bulk 16 — Android v2

A native Android workout companion built from the supplied 16-week dumbbell bulk program.

## Included
- 16-week automatic week calculation from first launch date
- Upper/Lower 4-day schedule
- Exercise-by-exercise, set-by-set logging for kg, reps and RIR
- Rest timers based on prescribed rest ranges
- Week 9 deload handling
- Double-progression guidance and 18 kg load-limit guidance
- Workout completion counter (64 planned sessions)
- Plan / Progress / Nutrition screens
- Local persistence with SharedPreferences; no account required

## Build
Open the `Bulk16Android` folder in Android Studio and run the app module on an Android 6.0+ device/emulator. Internet is not required at runtime.

The app uses only Android framework APIs, so there are no third-party UI dependencies to download.
